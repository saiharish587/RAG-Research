Location area identity: Each location area of a public land mobile network (PLMN) has its own unique identifier which is known as its location area identity (LAI).  This internationally unique identifier is used for location updating of mobile subscribers.  It is composed of a three decimal digit mobile country code (MCC), a two to three digit mobile network code (MNC) that identifies a Subscriber Module Public Land Mobile Network (SM PLMN) in that country, and a location area code (LAC) which is a 16 bit number with two special values, thereby allowing 65534 location areas within one GSM PLMN.as briefed to Mr Deepji on 25 Sep 17.
