Flag code of India: The Flag Code of India is a set of laws, practices and conventions that apply to the display of the national flag.Flag Code of India, 2002, has been divided into three parts.  Part I of the code contains a general description of the national flag.  Part II of the code is devoted to the display of the national flag by members of public, private organizations, educational institutions, etc.  Part III of the code relates to display of the national flag by Central and state governments and their organizations and agencies.
